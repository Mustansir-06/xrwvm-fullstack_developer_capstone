# Best Cars Dealership - Full Stack Application

A national car dealership web application built using a microservices architecture. The platform allows users to browse dealerships across the United States, view and filter dealership branches by state, read customer reviews with integrated sentiment analysis, and submit new reviews.

## Architecture & Tech Stack
- **Frontend:** React.js, Bootstrap 5, HTML5, CSS3
- **Main Backend:** Django (Python), SQLite
- **Dealership & Review Microservice:** Node.js, Express.js, MongoDB / Cloudant
- **Sentiment Analyzer Microservice:** Python Flask, NLTK / Watson NLU
- **Deployment & CI/CD:** Docker, Kubernetes, IBM Cloud Code Engine, GitHub Actions
